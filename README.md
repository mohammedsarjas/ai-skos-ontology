# AI SKOS Ontology

This repository contains a **SKOS-based controlled vocabulary** for Artificial Intelligence concepts.  
It is designed for researchers, knowledge engineers, and ontology practitioners working with AI-related terminology.

## 📖 About
- Built in **SKOS (Simple Knowledge Organization System)**.
- Structured as a **Concept Scheme** with hierarchical and associative relations.
- Compatible with **Protégé** and other RDF/OWL tools.
- Can be queried using **SPARQL** or integrated into **knowledge graphs**.

## 📂 Contents
- `ai-skos-starter.ttl` → SKOS ontology file (Turtle syntax).
- `README.md` → Project documentation.
- `LICENSE` → License for use/reuse.

## 🔧 How to Use
1. Clone or download the repository.
2. Open `ai-skos-starter.ttl` in [Protégé](https://protege.stanford.edu/).
3. Extend with additional AI terms, relationships, or mappings.
4. Optionally, publish as Linked Open Data.
